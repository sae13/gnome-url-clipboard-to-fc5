# Changelog

## 2.0.0 - 2026-08-28

- Replace the numeric timestamp slug with a compact six-character format.
- Encode month, day, and hour as single characters.
- Use one lowercase base-36 random suffix character.
- Relicense the project from MIT to GPL version 3 or later.

## 1.1.0 - 2026-08-28

- Shorten the original timestamp slug by removing minutes and seconds and using a two-digit year.

## 1.0.0 - 2026-08-28

- Initial GNOME Shell 48 release.
